# صلاتي اليوم — نسخة FastAPI + SQLite

واجهة عربية RTL لتتبّع الصلوات الخمس والسنن، مع حسابات بأسماء مستعارة وتاريخ محفوظ
لكل حساب. لا يطلب التطبيق اسمًا حقيقيًا أو عمرًا أو بريدًا إلكترونيًا. يمكن اختيار مدينة الحساب لحساب مواقيت الصلاة، دون طلب موقع الجهاز الدقيق.
استخدم بيانات وهمية فقط في هذه النسخة التجريبية.

## التشغيل المحلي

يلزم Python 3.12 أو أحدث. من مجلد prayer-app:

    python -m venv .venv
    . .venv/bin/activate
    python -m pip install -r backend/requirements.txt
    python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000

على Windows فعّل البيئة باستخدام `.venv\Scripts\activate` بدل السطر الثاني.
افتح http://127.0.0.1:8000 في المتصفح على الجهاز الذي يشغّل الخادم.
لن يكون عنوان localhost رابطًا إلى النسخة السحابية.

لا توجد حسابات افتراضية أو كلمات مرور مشتركة. أنشئ حسابًا باسم مستعار وكلمة مرور
تجريبية. تُنشأ قاعدة SQLite محليًا عند التشغيل ولا توجد قاعدة بيانات ضمن الحزمة.

## الاختبارات

يلزم Node 24 أو أحدث لاختبارات الواجهة؛ لا تحتاج الواجهة npm dependencies.

    python -m unittest discover -s backend/tests -v
    PYTHON="$PWD/.venv/bin/python" npm test
    npm run check

التحقق بتاريخ 1 أكتوبر 2026: 24 اختبار API ناجحًا، و10 اختبارات JavaScript ناجحة. يختبر
اختبار التكامل أحداث الواجهة الفعلية مع FastAPI عبر محوّل DOM صغير، بما في ذلك
التنقّل خلال ردود متأخّرة وتغيير الحساب. هذا ليس اختبار عرض بصري في متصفح.

يوجد اختبار متصفح اختياري في tests/ui_smoke.py. يحتاج Playwright وChromium.
لم يُشغّل هذا الاختبار الاختياري في التحقق الحالي. جُرّب الرابط العام فعليًا
في متصفح Codex: الدخول، سنة الفجر، حفظ المكافآت بعد إعادة التحميل، الإجمالي
والخروج. تفاصيل تشغيل النسخة العامة المؤقتة في [docs/PUBLIC-PREVIEW.md](docs/PUBLIC-PREVIEW.md).

## نموذج الصلاة

صفحة الإنجازات تعرض ملخص الفترة المختارة وميدالياتها وإنجازاتها وسجل أيامها:
هذا الأسبوع (السبت إلى الجمعة)، هذا الشهر الميلادي، أو آخر 30 يومًا بما فيها اليوم.
بعد اختيار مدينة في «حسابي»، تظهر مواقيت الصلاة حسب توقيت المدينة. صف الصلاة التي لم يحن وقتها يعرض «في انتظار الصلاة» وتُعطّل أزراره والسنن التابعة له، ويُتاح الوتر مع العشاء.
يعرض ملخص اليوم المكتسب من أصل الفرائض التي حان وقتها فقط: 27 ذهبية لكل فرض، وفضيات السنن التابعة له (الفجر 1، الظهر 3، العصر 0، المغرب 1، العشاء 2 مع الوتر). إذا حان وقت الفجر والظهر واكتملت الصلاتان، فالإنجاز 100٪ والأهداف 54 ذهبية و4 فضيات. قبل أول صلاة تكون النسبة 0٪. الأيام السابقة تحسب جميع الفرائض: 135 ذهبية و7 فضيات. صلاة الفرض في البيت تظل تمنح ذهبية واحدة.
بطاقات الإنجازات تعرض المكتسب من أصل المتوقع لكل الأيام المسجّلة في الفترة:
مجموع أهداف الأيام المسجّلة، مع حساب اليوم الحالي بحسب المواقيت والأيام الماضية كاملة. الحسابات التي لم تختر مدينة تحتفظ بالحساب السابق حتى اختيار المدينة.

- الفجر، الظهر، العصر، المغرب والعشاء فقط ضمن الفرائض
- شخصية واحدة كبيرة لكل فرض، تتبدّل: لم أصلّ بعد ← في البيت ← في المسجد
- سنة الفجر: ركعتان قبلية
- سنة الظهر: مجموعتان مستقلّتان من ركعتين قبلية، وركعتان بعدية
- العصر: خانات السنن فارغة
- المغرب والعشاء: ركعتان بعدية لكل منهما
- الوتر زر سنة مستقل بعد العشاء
- إنجاز اليوم من خمس فرائض فقط، والسنن منفصلة
- كل تحكم سنة مكتمل، بما فيه الوتر وكل مجموعة مستقلة من سنة الظهر القبلية، يمنح ميدالية فضية واحدة
- كل فرض في البيت يمنح ميدالية ذهبية واحدة، وكل فرض في المسجد يمنح ٢٧ ميدالية ذهبية إجمالًا
- تظهر مجاميع اليوم منفصلة، وتُحسب مجاميع الحساب من السجل المحفوظ؛ لذلك تتحدّث عند التبديل بين الحالات أو الأيام ولا تتكرر المكافآت

الدخول في النسخة المستقلة هو بالاسم المستعار وكلمة المرور فقط. لا تستخدم الواجهة
أو الخادم تسجيل دخول ChatGPT أو OpenAI.

إرشادات API وأمن الجلسات في backend/README.md. نسخة Worker + D1 السحابية
محفوظة بصورة مستقلة في المجلد prayer-cloud من الحزمة الكاملة.

## مواقيت المدينة

تُجلب المواقيت اليومية من [AlAdhan](https://aladhan.com/prayer-times-api)، باستخدام طريقة أم القرى للمدن السعودية والهيئة المصرية العامة للمساحة للمدن المصرية. يرسل الخادم إحداثيات المدينة المختارة والتاريخ وطريقة الحساب فقط، دون اسم الحساب أو سجله. يحتاج جلب المواقيت إلى اتصال بالإنترنت؛ عند تعذّر الجلب لا تُتاح صلوات اليوم قبل التحقق من وقتها، ولا تُعرض نسبة إنجاز غير مؤكدة.
